# Project Context: DataSentinal / UC10

## Primary Objective
Build a representative healthcare data pipeline and an AI-powered monitoring system capable of detecting data-quality and pipeline anomalies, assessing evidence, performing Root Cause Analysis (RCA), retrieving relevant knowledge, recommending actions, and eventually supporting controlled remediation.

## Core Systems
This project is distinctly divided into two separate, yet interacting systems:

### SYSTEM 1: Representative Healthcare Pipeline
The operational data pipeline itself. This system handles ingestion, validation, cleaning, transformation, feature engineering, and processed storage of healthcare data (claims and authorizations).

### SYSTEM 2: DataSentinal Monitoring / Intelligence Layer
The AI-powered intelligence layer that sits alongside the pipeline. It performs the hybrid anomaly detection, evidence fusion, RCA, and acts as the RAG knowledge assistant.
