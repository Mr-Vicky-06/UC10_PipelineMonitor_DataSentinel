# Accessibility Auditor Skill

This skill enforces strict accessibility standards for the DataSentinel UI.

*   Runs automated checks on components (especially Data Tables and Charts).
*   Verifies WCAG 2.2 AA compliance.
*   Checks for missing captions, row-count announcements, visible sort states, and sufficient color contrast.
