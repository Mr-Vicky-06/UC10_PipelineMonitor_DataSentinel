# Design Token / Tailwind Scaffolding Skill

This skill scaffolds the Tailwind CSS setup based on the DataSentinel enterprise design tokens.

*   Creates `tailwind.config.js` incorporating the strict color palette, spacing, and typography scales.
*   Enforces utility classes matching the bright/light enterprise theme.
