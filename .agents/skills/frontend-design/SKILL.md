# Frontend Design Skill

This skill enforces enterprise-grade UI/UX design rules.

1.  **Aesthetics:** Bright/light enterprise theme. No excessive rounded cards, no meaningless gradients, no excessive glassmorphism.
2.  **Typography:** Strong information hierarchy with readable, highly legible fonts (e.g., Inter, Roboto).
3.  **Color:** Restrained usage. Meaningful severity colors (CRITICAL, ERROR, WARNING, INFO).
4.  **Layout:** Meaningful whitespace, dense but readable presentation, standard admin-dashboard grids.
5.  **Prohibitions:** No purple/blue "AI" styling. No decorative charts or fake metrics.
