# Hallmark Skill

This skill enforces high-quality, professional design standards by auditing the UI against common "AI tells" and anti-patterns.

*   Checks for and prevents generic layouts (e.g., specific hero-section layouts, purple gradients).
*   Evaluates spacing, aesthetic quality, and typography.
*   Provides scored design critique to maintain enterprise standards.
