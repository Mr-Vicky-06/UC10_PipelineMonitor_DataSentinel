# Incident Responder Skill

This skill provides terminology and workflow patterns for the Alerts/Incidents UX.

*   Informs severity terminology (CRITICAL, ERROR, WARNING, INFO).
*   Provides concepts for incident lifecycle (DETECTED, INVESTIGATING, ACKNOWLEDGED, RESOLVED).
*   Informs UI structure for alert grouping and deduplication.
*   **PROHIBITED:** Must not modify anomaly detection, ML models, RCA logic, or ActionEngine logic.
